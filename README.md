## Микросервисная система управления задачами (Task Queue) с паттерном producer-consumer.

## Цель проекта

Разработать масштабируемую микросервисную систему управления очередями задач (Task Queue), основанную на паттерне producer‑consumer.

## Архитектура

Проект состоит из трех микросервисов:

- **API Gateway** (порт:8080) — принимает HTTP-запросы от клиентов
- **Queue Service** (порт:8081) — управляет очередью задач и их статусами
- **Worker Service** (порт:8082) — обрабатывает задачи из очереди
